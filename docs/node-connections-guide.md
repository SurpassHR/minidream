# 画布节点连接说明书

> 导演工作台（director-workbench）画布连线操作指南。
> 适用版本：协议 YAML v1 · chain 线性约束已启用。

---

## 1. 三种连线（边）与视觉区分

| 边类型 | 样式 | 语义 | 决定什么 |
|---|---|---|---|
| **ref** | 灰虚线 | **创作引用**：一个节点引用另一个节点的内容（素材、设定、剧本、提示词归属） | YAML 的 `keyframes` 标签、分镜的 `prompt` 归属 |
| **chain** | 琥珀实线 | **链式参考**：后一个分镜引用前一个分镜的**末帧**作为首帧（mmh3 分段生成核心） | **剧情顺序 = YAML `segments[]` 顺序** |
| **exec** | 蓝实线 | **执行流**：生成任务的消费关系（提示词 → 生成任务） | 提交生成时取哪份 YAML |

---

## 2. 如何拖拽连接

### 2.1 新建连线（拖线）

1. 把鼠标移到任意节点边缘，出现**连接点（小圆点）**
2. **按住左键**从连接点拖出，拖到目标节点上松开
3. 松手后按端点类型**自动推断**边类型（见下表），立即生效并写入快照

**自动推断规则：**

| 拖线方向 | 生成的边类型 |
|---|---|
| shot → shot | **chain**（链式参考） |
| 任意端点是 generation 节点 | **exec**（执行流） |
| 其他任意组合 | **ref**（创作引用） |

> 示例：把「SHOT 01」拖到「SHOT 02」→ 自动生成琥珀色 chain 边，剧情顺序即 SHOT 01 → SHOT 02。

### 2.2 修改连线类型

**右键点击连线** → 弹出菜单，可切换 `ref / chain / exec` 或删除连线。
- 切换为 chain 时后端会重新校验线性约束，**违反规则会被拒绝**（画布会回滚）
- 菜单中当前类型高亮

### 2.3 分镜节点左侧的多接口圆点（剧情 / 文字 / 视频 / 图像）

分镜是串联剧情与素材的核心节点，其**左侧**按类型提供四组输入接口圆点：

| 接口 | 圆点 id | 典型连接来源 | 动态追加 |
|---|---|---|---|
| **剧情** | `chain-0`（固定 1 个，琥珀色） | shot → shot 的 chain 边 | 否（chain 线性约束至多一个入链） |
| **文字** | `text-0` / `text-1` … | prompt（提示词归属）、script（剧本段落）、subject（设定）、文本素材 | 是 |
| **视频** | `video-0` / `video-1` … | 视频素材（asset/vid）、generation 产物 | 是 |
| **图像** | `image-0` / `image-1` … | keyframe（关键帧）、图片素材（asset/img） | 是 |

规则：
- **标题在节点最上方**，接口圆点在标题下方；每组**初始各 1 个圆点**，圆点旁有类型标签（剧情/文字/视频/图像）。
- 素材组圆点**被占用（已有入边）时自动追加一个新圆点**，始终保证至少 1 个空闲圆点可拖。
- **类型校验**：拖线时按源节点类型校验接口——文字节点不能连图像/视频接口，keyframe 不能连文字接口……
  不匹配会**拒绝并弹出提示**（后端同样兜底校验，返回 `EDGE_INVALID`）。
- **剧情链自动纠正**：shot → shot 的 chain 边无论拖到哪个圆点/节点主体，一律落到剧情接口 `chain-0`。
- **松手在节点主体也能连接**：未命中具体圆点时，按边类型自动分配——chain → 剧情接口；
  ref/exec → 源节点类型对应组的最小空闲圆点（不再需要精确对准圆点）。
- 圆点 id 持久化在边的 `targetHandle` 字段（写图快照），刷新/回滚后仍然正确；存量旧边（无 `targetHandle`）按边类型/源类型补齐渲染。
- 右侧仍是单一输出点（chain 出，线性约束保证至多一个后继）。

### 2.4 快捷键与画布拖放

| 操作 | 行为 |
|---|---|
| **Delete / Backspace** | 删除选中的节点（连带边）和连线；节点删除同步后端并写入快照（可回滚） |
| **Ctrl / Cmd + 拖拽** | 框选（rubber-band selection）多个节点（原 Shift 已改为 Ctrl/Cmd） |
| **素材拖到画布** | 从素材库拖出素材松手到画布 → 创建素材节点，**节点中心对准松手处光标**（画布平移/缩放后位置依然正确） |
| 单击节点后 Delete | 删除该节点（等同右键 → 删除节点） |

### 2.5 删除连线

- 方法一：**选中连线（点击）后按 Delete 键**
- 方法二：**右键连线 → 🗑 删除连线**

删除立即同步后端并写入快照（可回滚）。

## 3. 哪些节点可以直接连接

### 3.1 强制规则（后端校验，违反即报错）

| 约束 | 规则 |
|---|---|
| **chain 只能 shot → shot** | 链式参考只存在于分镜之间 |
| **chain 必须线性** | 每个分镜**至多一个前驱、一个后继**；整条链**无环** |
| **边两端节点必须存在** | 删除节点时其边自动移除 |
| **同类型同向重复边** | 拒绝（ref A→B 建两次会报"边已存在"） |

### 3.2 推荐连接组合（ref / exec 无类型限制，但以下组合有业务含义）

**ref（创作引用）——按目标节点分：**

| 源 → 目标 | 含义 | 对 YAML 的影响 |
|---|---|---|
| keyframe → shot | 分镜引用关键帧 | → 该段的 `keyframes: [KF0, KF1]`（取连线标签，无标签用节点标题） |
| prompt → shot | **提示词归属**：该分镜用哪份提示词 | → 该段的 `prompt`（**每个分镜必须有，缺失导出报错**） |
| asset → shot | 素材引用（图片/参考视频） | 仅标注（ComfyUI 侧取用） |
| script → shot / prompt | 剧本段落引用 | 仅标注（提示词文本需自行写入 prompt 节点） |
| subject → prompt / shot | 设定/角色引用 | 仅标注 |
| keyframe → keyframe / 其他 | 自由引用 | 仅标注 |

**exec（执行流）：**

| 源 → 目标 | 含义 |
|---|---|
| prompt → generation | 生成任务消费这份提示词 YAML |
| generation → shot | 生成产物归属于该分镜 |

**chain（链式参考）：**

| 源 → 目标 | 含义 |
|---|---|
| shot → shot | 后段以前段末帧为参考（`<Picture n+1>` 机制）；**同时决定剧情顺序** |

## 4. chain 线性约束详解（暂不支持分支）

- 一条 chain 边 = "前一个分镜 → 后一个分镜"
- **每个分镜最多一个入链、一个出链** → 全图形成一条或多条**线性链**
- 成环（A→B→C→A）会被拒绝
- 想调整剧情顺序：**删除旧 chain 边，重新拖线**（或改边类型）
- 没有 chain 的分镜：按 `fields.start` 或标题序号排序，排在链后

**常见报错：**
```
EDGE_INVALID: 分镜 xxx 已有出链，一个分镜只能有一个后继（暂不支持分支）
EDGE_INVALID: 分镜 xxx 已有入链，一个分镜只能有一个前驱（暂不支持分支）
EDGE_INVALID: chain 边成环：分镜链必须线性
EDGE_INVALID: chain 边只允许连接 shot → shot（分镜链式参考）
```

## 5. 连接如何映射到 YAML 输出

画布右键 → **「⇩ 导出 Prompt YAML」**，映射规则：

| 画布要素 | → YAML |
|---|---|
| chain 拓扑序（线性链） | `segments[]` 顺序（**与底部时间线一致**） |
| shot 标题 / 序号 | 段 `title` / `shot` |
| shot 的 `fields.duration`（或 frames/fps，缺省 3.75s） | 段 `duration`（全有或全无） |
| keyframe → shot 的 ref 边 | 段 `keyframes` 标签 |
| prompt → shot 的 ref 边 | 段 `prompt`（缺失 → **导出报错**，列出缺失分镜） |
| 未被引用的 prompt 节点 | 顶层共享 `prompt` |
| project 节点标题 | 顶层 `project` |
| params 节点的 `fields.mode` | 顶层 `mode` |
| seed | **自动填 42**（shot 显式 `fields.seed` 时尊重该值） |

## 6. 快速上手（3 步）

1. **建分镜**：右键画布空白 → 「＋ 新建分镜节点」（SHOT 01、SHOT 02…）
2. **连剧情**：SHOT 01 拖到 SHOT 02 → 自动生成琥珀 chain 边
3. **连提示词**：prompt 节点（右键新建）→ 拖 ref 边到对应分镜，在节点面板写入英文 H3 提示词
4. **导出**：画布右键 → 「⇩ 导出 Prompt YAML」→ 复制 → 粘贴到 ComfyUI 的 MMH3 Prompt YAML 节点

## 7. 版本快照与撤销

| 操作 | 行为 |
|---|---|
| **自动快照** | 每次修改画布自动留痕，**最多保留最近 300 次**（超出后最旧快照合并进基线，历史重建依然正确） |
| **点击版本行** | **直接回滚**到该快照（免确认，不追加新快照） |
| **灰色版本行** | 当前快照（HEAD）**之后**的快照为「未来分支」：显示灰色，回滚后可 `Ctrl+Y` 重做回去 |
| **新操作覆盖未来** | 回滚后执行写操作会覆盖未来快照——**弹确认框**，确认后自动重放该操作并丢弃未来分支 |
| **Ctrl+Z / Ctrl+Y** | 撤销 / 重做（等价于在快照链上后退/前进；输入框内不拦截，保持文本编辑行为） |
