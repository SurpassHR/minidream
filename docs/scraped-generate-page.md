# 即梦「生成」页抓取数据（登录后）

> 抓取时间：2026-08-21，playwright 真实浏览器 + 已登录抖音授权账号
> 用途：导演工作台 v2 复刻参照。品牌文案已替换为「导演工作台」，技能卡围绕剧本/分镜/视频创作。

## 页面整体结构

- 左侧图标栏（76px）：Logo + 灵感/生成/资产/画布（竖排）+ 底部会员/积分（登录后：会员6折/25积分/开会员/领积分）
- 会话边栏（240px 白底）：开启创作 + 新对话 + 最近（对话列表，标题取用户首条消息）
- 主区域：
  - 空状态：「你好，想创作什么？」+ 热门技能卡 3 张
  - 聊天状态：消息流 + composer 贴底
- Composer（994px 白底圆角 24px）：输入框 + 底部工具行

## 热门技能卡（3 张，登录后可见）

1. **叙事短片导演分镜**（官方/热门技能）
   描述：以森海荧光导演分镜方法论产出叙事短片：导演意图书、九列分镜表、4~15s Clip 表与逐 Clip 提示词，直至成片。
2. **系列套图生成**
   描述：将母版提示词/参考图/产品图/角色设定抽象为稳定的系列视觉母体，生成风格统一但变量清晰的系列图片。
3. **爆款电商短视频题材创意**
   描述：电商短视频创作助手，支持多题材选择、时长配置，每个题材生成5组差异化方案。

卡片结构：图片 + 左上「热门技能」tag + 底部黑渐变 overlay（标题 + 「试一试」按钮）+ 描述文字

## Composer 工具行（3 个触发器 + 2 个工具按钮 + 发送键）

### 1. Agent 模式（combobox，创作类型）
选项 7 项：`Agent 模式`(默认选中) / 图片生成 / 视频生成 / 音乐生成 / 配音生成 / 数字人 / 动作模仿
选中项：高亮 + 对勾。面板标题「创作类型」。

### 2. 自动（按钮，生成偏好面板）
- 生成偏好：图片(默认) / 视频
- 选择比例：智能(默认) / 21:9 / 16:9 / 3:2 / 4:3 / 1:1 / 3:4 / 2:3 / 9:16
- 其他设置：图片 4.0

### 3. 使用技能（combobox）
- 顶部搜索框「搜索技能」+「更多技能」按钮
- 技能列表 4 项（均带「官方」tag）：
  - 剧情短片：帮你自动生成故事大纲、分镜脚本并产出短片
  - 电商套图：生成风格统一的商品全套视觉素材，适用于各大电商平台
  - 海报设计：生成更有创意的海报内容，擅长营销场景和节日热点
  - 品牌设计：根据公司名称、业务与客群，生成品牌 Logo 与视觉方案
- 底部：「用 Agent 创建技能」/「管理技能」

### 4. 工具按钮
- 上传素材按钮：点击触发系统文件选择器（无页面弹层）
- 添加主体按钮：点击弹出「可能@的内容」菜单 → 未创建主体时显示「你还没有创建过主体」+「创建主体」按钮

### 5. 发送键
- 圆形，输入为空时 disabled，有内容时启用（品牌色）

## 生成流程中间态（发送后 → 生成中）

用户消息（右侧气泡）显示后，Agent 回复区分阶段渲染：

1. **任务响应中…** 状态（思考中）
2. Agent 思考日志段落（多段文本，如「我先加载视频创作优化技巧…」「检测到当前模型为会员专属版本…」）
3. 技能加载提示：「已加载技能：视频Prompt Skill」
4. 任务进度卡：(0/1) 视频生成中...（完成度计数）
5. 任务元数据行：时间 / 生成模式 / 操作类型 / 资产库
6. 排队提示：「排队中... 1 个任务排队中」+「取消生成」按钮
7. 完成提示语：「已提交生成…完成后你就可以直接查看成片效果啦」
8. 「以上内容由 AI 生成」标注
9. 「本次消耗 75 积分」标注
10. 「重新生成」按钮
11. 建议按钮：「按这个场景开始生成视频」

## 会话边栏
- 新对话标题取用户首条消息（如「女孩森林遇发光鹿视频生成」→「帮我把这段做成视频：一个…」）
- 分组：最近 / 今天
