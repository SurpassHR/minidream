# image_krea2_turbo_t2i

## 用途

根据输入的提示词生成图像，支持正面提示词、负面提示词、图像宽度和高度等参数控制。

## 输入

- 提示词：用于图像生成的文本提示词。

## 可控制参数

- text-551：负面提示词，使用tag格式，例如 `(anime:-1)` 表示禁止动漫风格图像，必须使用 `(<tag>:-1)` 格式表示禁止 `<tag>`。
- text-555：正面提示词，使用自然语言描述。
- value-582：图像宽度（整数）。
- value-583：图像高度（整数）。

## 输出

- Preview Image：生成的图像预览。

## 使用规则

1. 正面提示词（text-555）为必填项，使用自然语言描述要生成的图像内容。
2. 负面提示词（text-551）使用tag格式，每条禁止项必须以 `(<tag>:-1)` 格式书写，多个禁止项用逗号分隔。
3. 宽度（value-582）和高度（value-583）为整数数值，必须大于0。
4. 若输入中提供了提示词，应将其作为正面提示词使用。
