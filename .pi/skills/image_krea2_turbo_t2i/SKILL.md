# image_krea2_turbo_t2i

## 用途

根据用户提供的正面提示词生成图像。支持负面提示词（禁止特定风格，如动漫风格）以及自定义图像宽度和高度。输出为一张生成的图像。

## 输入

- **提示词**（必须）：用于描述期望生成的图像内容，使用自然语言描述。
- 工作流包含两个"提示词"输入字段，其中标记为 primary 的字段为主要提示词输入。

## 可控制参数

| 参数 ID | 参数名 | 类型 | 说明 |
|---------|--------|------|------|
| 不适用 | text-551 | STRING | **负面提示词**，用于禁止某些风格或内容。示例：`(anime:-1)` 表示禁止动漫风格。 |
| 不适用 | text-555 | STRING | **正面提示词**，使用自然语言描述要生成的图像。 |
| 不适用 | value-582 | INT | **图像宽度**，以像素为单位。 |
| 不适用 | value-583 | INT | **图像高度**，以像素为单位。 |

## 输出

- **Preview Image**（图像）：生成的图像预览。

## 回复协议

- 用户可在回复协议编辑器中配置思维链、widget 值、提示词、路由和结果摘要的显示方式；不要自行重复结构化展示内容。
- 回复协议支持普通文本、可折叠容器、Markdown 和代码块组合；不输出无意义的生成状态句，生成的图像始终在对话气泡外展示。

## 使用规则

- 正面提示词（text-555）为必填，用自然语言描述希望生成的图像内容。
- 负面提示词（text-551）可选，用于排除不期望的风格或元素。格式为 tag，例如 `(anime:-1)` 表示严格禁止动漫风格。
- 图像宽度（value-582）和图像高度（value-583）为整数像素值，可自定义输出尺寸。
- 描述应具体明确，避免歧义，以获得更准确的生成结果。
